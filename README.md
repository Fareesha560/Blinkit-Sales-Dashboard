# Blinkit Sales Analysis Dashboard

## Project Overview
This project analyzes Blinkit's sales performance using Power BI. The dashboard provides insights into sales, product categories, outlet performance and customer preferences.

## Tools Used
- Power BI
- Power Query
- DAX
- Excel

## Key Insights
- Total Sales: $1.20M
- Analysis of outlet performance.
- Product category comparison.
- Sales trends and customer preferences.
